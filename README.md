# Система управления торговыми стендами

Консольное приложение для учета торговых стендов и управления их бронированием.

## Возможности
- просмотр и поиск торговых стендов;
- фильтрация стендов по площади;
- проверка доступности стенда на конкретную дату;
- создание и отмена бронирований;
- сохранение данных в JSON-файлах.

## Структура проекта
- `main.py` — точка запуска и меню;
- `stands.py` — работа со стендами (добавление, поиск, сортировка);
- `bookings.py` — работа с бронированиями;
- `storage.py` — сохранение и загрузка данных;
- `utils.py` — вспомогательные функции ввода;
- `data/` — JSON-файлы данных;
- `tests/` — автоматизированные тесты.

## Требования
- Python 3.x
- pytest
- flake8

Установка зависимостей:
`pip install -r requirements.txt`

## Запуск программы
`python main.py`

## Запуск тестов
`pytest`

## Проверка качества кода
`flake8`
