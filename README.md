# Система управления торговыми стендами

## Назначение

Приложение предназначено для управления торговыми стендами на ярмарках. Оно помогает проверить доступность стенда, оценить возможность бронирования продавцом и рассчитать предварительную стоимость размещения.

## Целевая аудитория

Основные пользователи системы:

- организаторы городских и тематических ярмарок;
- администраторы торговых площадок;
- продавцы, которые хотят забронировать стенд для участия в ярмарке.

## Предметная область

Предметная область связана с организацией ярмарок, размещением торговых стендов и обработкой заявок продавцов. Организатору важно знать, активна ли ярмарка, свободен ли стенд, подходит ли продавец по требованиям и сколько будет стоить бронирование.

## Основные сущности

- Ярмарка
- Стенд
- Продавец
- Бронирование

## Основные функции

- проверка возможности бронирования стенда на выбранную дату;
- проверка соответствия продавца требованиям ярмарки;
- расчет предварительной стоимости бронирования;
- отображение краткой информации о ярмарке, стенде и продавце.

## План развития

На следующих этапах планируется:

- расширить сценарий с использованием коллекций, циклов и функций;
- добавить модели предметной области;
- разработать веб-приложение на Django;
- подключить базу данных;
- реализовать пользователей и разграничение доступа;
- разработать API;
- контейнеризировать приложение;
